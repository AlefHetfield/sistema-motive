# Fontes do PDF habitacional

Família CAIXA Std nos pesos Regular, SemiBold e Bold, a mesma incorporada ao PDF de referência fornecido pelo usuário.

Origem: arquivos públicos do simulador habitacional da CAIXA, convertidos de WOFF para TTF para incorporação pelo jsPDF:

- https://simuladorhabitacao.caixa.gov.br/assets/fonts/caixa/CAIXAStd-Regular.woff
- https://simuladorhabitacao.caixa.gov.br/assets/fonts/caixa/CAIXAStd-SemiBold.woff
- https://simuladorhabitacao.caixa.gov.br/assets/fonts/caixa/CAIXAStd-Bold.woff

Os arquivos completos preservam o repertório de caracteres; os subconjuntos extraídos do PDF de referência não devem ser usados para novos documentos.
